# Floush Logistics

**Delivering Excellence. Driving Trust.**

Floush Logistics LLC is being built as a technology-enabled freight transportation company with a modern public brand, disciplined operations, and a long-term AI and logistics intelligence layer.

## v0.1

This repository currently includes:

- Public Floush Logistics homepage
- Services and company positioning
- Quote request experience
- Internal operations dashboard shell
- Floush brand system
- TypeScript + Next.js application foundation

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Operations dashboard:

`http://localhost:3000/dashboard`

## Validate

```bash
npm run check
npm run build
```

## Product direction

Planned operating modules include:

- Customers and brokers
- Loads and stops
- Dispatch
- Drivers
- Trucks and trailers
- Documents and proof of delivery
- Invoices and payments
- Fuel and expenses
- Maintenance
- Driver settlements
- Financial and operational KPIs
- AI recommendations and outcome tracking

## Floush Intelligence

The long-term intelligence layer is intended to support load profitability scoring, deadhead optimization, lane analysis, broker performance, maintenance forecasting, invoice risk, and dispatch decision support.

The goal is to build the operating system and data foundation of a much larger carrier while Floush is still small.
